# Shadow & Shine Daily — build tools

One new original text per level (1 Sprout · 2 Seedling · 3 Sapling · 4 Tree) every day.

## Files
| Path | What |
|---|---|
| `shadow/daily/dNNN/scripts.json` | The day's 4 scripts (same shape as e-languages `lib/shadowing/content.json` scripts, plus `topic`) |
| `shadow/daily/index.json` | State: every past day `{day, date (Asia/Seoul), levels: {lv: {title, topic, genre}}}` — generated by `build_pages.py` |
| `shadow/daily/l{lv}/dNNN/` | `us-1.mp3` normal · `us-slow.mp3` slow · `us-2.mp3` echo/repeat · `uk-*` British · `index.html` player |
| `shadow/daily/index.html` | List of all days (linked from the root Audio Library page) |

## Tools
- `build_audio.py` — Kokoro TTS, runs in GitHub Actions (`.github/workflows/shadow-daily.yml`), triggered by pushing `shadow/daily/d*/scripts.json`. Rebuilds a level only if a file is missing or its lines changed (`.lines.sha1`). Commits with `[skip ci]`.
- `build_pages.py` — player pages, `index.json`, daily list and the root-index block. Pure Python; run locally before pushing (the workflow also runs it).
- `build_worksheets.py` — A4 PDFs (shadowing worksheet, dictation worksheet, answer key & teacher script) via HTML → Chromium (Playwright). Needs `segno` and the Noto Sans CJK KR font. Output: `ShadowShine_Daily_DNNN_L{lv}_{Level}.pdf`.

## Voices (keep fixed from day to day)
- American: Kokoro `af_heart` (lang `a`)
- British: Kokoro `bf_emma` (lang `b`)
- Model `hexgrad/Kokoro-82M`, 24 kHz mono, MP3 96 kbps.
- Normal speed factor by level: L1 0.72 · L2 0.75 · L3 0.75 · L4 0.80, with line gaps 1.5 / 1.3 / 1.2 / 0.8 s — about 80 / 100 / 120 / 140 wpm, matching the level wpm bands. Slow = normal × 0.8 (gaps × 1.4). Echo = normal speed with a pause after each phrase (1.2× phrase length + 0.8 s) and after the whole line.

Changing a voice or speed rebuilds every day the next time the workflow runs (the hash includes them).
